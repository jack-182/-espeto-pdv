2. Clique no botão "New repository secret" (verde)

    • Digite o Name
    • Cole o Value usando o botão [Copy]

1. Clique no link acima (vai abrir Netlify)

3. Vá para Settings → Build & Deploy → Environment
4. Clique "Edit variables" (ou New variable)
5. Para cada item abaixo:
    • Digite o Key
    • Cole o Value usando [Copy]
    • Clique Save

3

Trigger Novo Deploy

⚙️ O que fazer:

No GitHub:
1. Ir para GitHub Actions
2. Clicar em qualquer workflow
3. Clicar "Run workflow" (botão azul)

Ou no Netlify:
1. Ir para Netlify Dashboard
2. Selecionar seu site
3. Ir para Deploys
4. Clicar "Trigger deploy" → "Deploy site"
4

Aguardar Build (5-10 minutos)

⚙️ O que fazer:

• GitHub Actions irá rodar os testes
• Netlify irá fazer npm run build
• Você pode acompanhar em tempo real
• Quando terminar, verá ✅ (sucesso) ou ❌ (erro)
5

Testar Login em Produção

⚙️ O que fazer:

1. Abrir sua URL Netlify (ex: https://seu-site.netlify.app)
2. Clicar em "Entrar no Google"
3. Fazer login com sua conta Google
4. Se funcionar → ✅ Parabéns! Firebase está working
✅ Se o login funcionar, significa que Firebase está corretamente configurado em produção!
